# 选课测试版安装与验收

## 安装标识

- 应用名称：`NEU e码通·选课测试版`
- 应用 ID：`com.neko.neuecode.sandbox`
- 版本名：`5.33-recharge-auto-cas-webview-enrollment-sandbox`
- 最低 Android 版本：API 23

Debug 测试版使用独立应用 ID，可与正式版并存，不会覆盖正式客户端。

## 验收重点

1. 底部导航可以进入“选课”。
2. 点击同步按钮后，在选课官网选择当前轮次并进入课程列表；返回后页面不显示 token、Cookie 或 batchId。
3. “课程”页可以分类、搜索、分页，并标记官网已选与课表内教学班。
4. “已选”页显示三个只读接口的合并结果及当前课表；局部读取失败会显示警告。
5. “待选”页可以调整本地优先级；权重模式可调整本地目标权重并显示预算。
6. “预览”页只显示脱敏占位符，点击后只产生“本地模拟”结果。

## 发布边界

测试版只动态读取当前进程内的 `Authorization`、`batchId` 与 WebView Cookie，用于课表、课程目录和三类已选接口。它不持久化或展示会话头，不读取 `secretVal`，不调用 `add`、`del`、`weightAdd`，不创建选课轮询或后台任务。主人拍板前不提升正式版本号、不提交发布构建、不上传 Worker 或 R2。
